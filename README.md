## How This Website Was Crafted

When designing this website, I wanted every interaction to feel gentle, physical, and intentional:

* **Fast and Lightweight**: Built using **Astro**, meaning almost every page is pre-rendered into pure, static HTML and CSS. There is no heavy JavaScript bundle sent to your browser just to read a paragraph of text.
* **A Tactile Pull-Cord Lamp**: In the top navigation, there is a small brass lamp hanging from a physics cord. You can pull the chain down with your mouse or finger to toggle between day and night mode. It produces a soft, analog click synthesized in real-time through the Web Audio API.
* **Zero Audio Files Downloaded**: Every sound on the site—the soft clicks, the chime when switching colors, the warm light bulb snap—is generated mathematically using pure browser sine waves and filters. No audio files are ever downloaded over your connection.
* **A 60-Second View (`/quick`)**: For busy recruiters, hiring managers, and friends who only have a minute to spare, there is an executive summary route that puts the essential facts, project links, and contact channels on one quiet page.
* **Subtle Themes**: You can choose an accent color (Electric Blue, Soft Violet, Rose, Warm Amber, or Teal) that feels comfortable to your eyes.

## Principles I Live and Code By

1. **Be kind in the code you leave behind.**  
   Someone will have to read your pull request or fix a bug late at night. Write clear names, write small functions, and explain *why* something was done, not just *what*.

2. **Respect the person on the other end.**  
   Not everyone has high-speed fiber internet or the newest smartphone. A good web page should load quickly, respond immediately to touch, and never jump around while reading.

3. **Steady, honest progress.**  
   Good craftsmanship is never rushed. Writing code every single day, fixing small rough edges, and listening to feedback compounds into work you can be quietly proud of.
